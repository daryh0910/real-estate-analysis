# 2026-05-03 아파 투자 TradingView화 작업 기록

아파 투자를 부동산 투자용 TradingView 수준의 분석 도구로 발전시키기 위해, 2026-05-02~2026-05-03에 구현한 기능과 검증 결과를 기준점으로 남긴다.

이번 작업의 핵심은 세 가지다.

1. 자유차트, 전략검증, 지역검색기, 전세-매매 선행 신호 v1 구현

3. 조건빌더, 백테스트, 저장 기능을 실제 투자 판단에 쓸 수 있도록 보강

## 구현 내용

### 1. TradingView형 분석 v1

- 상위 탭을 `Overview`, `수요공급분석`, `거래현황`, `매물찾기`, `자유차트` 중심으로 재구성
- `자유차트 > 슈퍼차트` 추가
- `자유차트 > 전략검증` 추가
- `매물찾기 > 지역검색기` 추가
- `수요공급분석 > 전세-매매 선행 신호` 추가
- 어려운 통계 용어를 직관적인 표현으로 수정
  - Granger 인과성 -> 선행 신호 반복성
  - p-value -> 통계 신뢰도 / 우연 가능성
  - lag -> 먼저 움직인 기간

### 2. 데이터 선택과 출처 표시

- 지표군 기반 데이터 선택 추가
  - 가격, 전세, 거래, 수요, 공급, 심리/금리, 파생
- 예시
  - 가격: 실거래 평균가격, 실거래 m2당 가격, BOK 아파트매매가격지수, KB 선도50지수
  - 전세: 전세 보증금평균, 전세 m2당 보증금, BOK 전세가격지수, KB J-PIR
- `Overview`에 데이터 출처 및 최신성 표 추가
- 차트 하단에 선택 지표의 출처 캡션 표시
- 조건빌더에서도 지표군을 먼저 고르고 지표를 선택하도록 변경

### 3. 조건빌더 v2

기존 단순 비교 조건에 시계열 조건을 추가했다.

| 조건 유형 | 의미 |
|---|---|
| 값 비교 | PIR < 15 같은 단순 임계치 조건 |
| 연속 상승 | n기간 연속 상승한 지표 |
| 연속 하락 | n기간 연속 하락한 지표 |
| 이동평균 위 | 현재 값이 이동평균보다 위에 있는 상태 |
| 이동평균 아래 | 현재 값이 이동평균보다 아래에 있는 상태 |
| 고점 대비 | 최근/누적 고점 대비 하락률 |
| 하락 후 반등 | 고점 대비 충분히 하락한 뒤 저점에서 반등한 상태 |

`evaluate_condition_rules()`는 중첩 조건도 받을 수 있게 확장했다.

### 4. 선행신호와 백테스트 보강

- `compute_lead_lag_signal()`에 ADF 기반 정상성 확인과 자동 차분 분기 추가
- 비정상 시계열로 인한 허위 선행신호 위험을 줄임
- `run_region_backtest()`에 중복 신호 쿨다운 추가
- 성공률 기준을 `0% 초과` 고정값이 아니라 사용자 입력 기준으로 변경
- 최대하락폭 정의를 더 명확히 표시
  - 신호별 선택 기간 수익률 중 가장 낮은 값을 지역별로 다시 최저 집계

### 5. 저장 기능

기존 `board.db` SQLite 인프라를 확장했다.

| 테이블 | 용도 |
|---|---|
| `saved_charts` | 자유차트 설정 저장 |
| `saved_conditions` | 전략검증/지역검색 조건 저장 |
| `watchlists` | 관심지역 저장 및 알림 대상 표시 |

앱 UI 연결:

- 자유차트 저장/불러오기/삭제
- 전략검증 조건 저장
- 지역검색 조건 저장
- 지역검색 결과에서 관심지역 등록
- 관심지역 목록 확인
