# 대장아파트 탭 구현 계획

## 1. 요구 재진술과 가정

- 요구: 전국 시군구별로 거래가 충분히 활발한 단지 중 평당가격이 높은 대표 아파트를 선정하고, 선택한 구의 대표 단지 가격·거래량 흐름을 보여주는 독립 기능 탭을 추가한다.
- 가정 1: 단지 선정은 최신 데이터월 기준 최근 24개월을 기본 관찰기간으로 한다.
- 가정 2: "거래량이 많고 평당가격이 가장 높은"은 구별 거래량 상위 30%이면서 최소 3건 이상인 단지를 후보로 삼고, 후보 중 거래량 가중 평균 평당가격이 가장 높은 단지를 선택하는 방식으로 정량화한다.
- 가정 3: 평당가격은 원본의 거래금액(만원) / 전용면적(m²) × 3.305785로 계산한다.
- 가정 4: 같은 이름의 단지를 구분하기 위해 지역코드 + 법정동 + 아파트명을 단지 식별자로 사용한다.
- 가정 5: 해제된 거래와 가격·면적·지역·단지명이 유효하지 않은 행은 집계에서 제외한다.

## 2. 작업 분해

1. 단지 월별 캐시 로더 구현
   - `data_loader.py`에 단지 월별 Parquet 경로와 청크 집계 로더를 추가한다.
   - 산출 컬럼: 시도, 지역코드, 법정동, 아파트, 연도, 월, 연월, 평균가격, 거래량, 평균단가_per_m2, 평균평당가격.
   - 여러 청크에 걸친 같은 단지는 거래량 가중 평균으로 다시 합친다.
2. 대장아파트 선정 로직 구현
   - 신규 `leader_apartment.py`에 입력 검증, 최근 N개월 필터, 구별 후보/대표 선정, 대표 단지 전체 월별 흐름 추출 함수를 둔다.
   - 선정 결과에 관찰기간, 거래량, 평균평당가격, 후보 내 순위/근거를 포함한다.
3. Streamlit 독립 페이지 추가
   - `app.py` 상위 segmented navigation의 거래현황 다음에 `🧭 대장아파트`를 추가한다.
   - 시도·구·관찰기간·최소 거래건수 선택, 구별 대표 단지 표, KPI, 평당가격 라인 + 거래량 막대 흐름을 제공한다.
   - 데이터 부재·후보 부재를 명시적으로 안내하고 기존 다크 테마/차트 등록 패턴을 따른다.
4. 배포 캐시 생성 경로 보강
   - `build_cache.py`에 새 단지 캐시 빌드를 포함하고 실제 원본에서 `cache/apt_complex_monthly.parquet`를 생성한다.
5. 테스트 추가·정비
   - 신규 순수함수 단위 테스트로 거래량 부족 고가 단지 제외, 구별 선정, 동명 단지 분리, 결정적 동률 처리, 흐름 추출을 검증한다.
   - 앱 정적 테스트에서 신규 페이지·가이드·차트 계약을 확인한다.
   - 현재 segmented navigation과 불일치하는 기존 탭 순서 정적 테스트를 현 구조에 맞게 최소 수정한다.

## 3. 리스크와 함정

- `app.py`에는 사용자 미커밋 변경 466줄이 있으므로 기존 변경을 유지하고 신규 블록만 좁게 패치한다.
- 원본 CSV는 약 911MB이며 배포 환경에는 존재하지 않는다. 앱 실행 중 원본을 읽지 않고 사전 생성 Parquet만 사용해야 한다.
- 단순 최고 평당가 방식은 1건짜리 이상치 단지를 뽑을 수 있으므로 거래량 후보군을 먼저 제한한다.
- 청크별 평균을 단순 평균하면 왜곡되므로 반드시 거래량 가중 재집계한다.
- 최신 24개월만으로 대표를 선정하되, 선정된 단지의 흐름 차트는 사용자가 선택한 전체 표시기간을 사용한다.
- 파일 이동·삭제·외부 배포·커밋은 하지 않는다. 실제 Streamlit Cloud 반영은 별도 커밋/푸시가 필요하다.
- 새 Parquet가 GitHub/Streamlit Cloud 파일 크기 한도를 넘는지 생성 후 확인한다.

## 5. 검증 방법

1. 완료기준 대조
   - synthetic DataFrame 테스트와 실제 캐시 집계에서 구별 대표 결과 건수·단지명·선정 근거를 확인한다.
   - 새 캐시를 임시로 원본 경로와 분리한 상태에서 loader가 Parquet만 읽는지 확인한다.
2. 잔존 참조 grep
   - `rg`로 신규 탭명, loader명, 캐시 경로, 컬럼명을 확인하고 임시명/옛 탭 가정이 남지 않았는지 점검한다.
3. 실행 테스트
   - `python -m py_compile app.py data_loader.py leader_apartment.py build_cache.py`
   - 관련 단위·정적 테스트와 전체 `pytest -q`
   - `streamlit run app.py --server.headless true` 기동 후 HTTP 상태 확인
   - 새 Parquet 스키마·크기·최신월·지역수·거래량 합계 대조
