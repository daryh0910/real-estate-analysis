# 매수판단 탭 v1 구현 계획

> **For Hermes:** 이 계획은 subagent-driven-development 방식으로 태스크별 구현·검토한다. 구현 전 테스트를 먼저 작성하고, 기존 사용자 변경사항은 되돌리지 않는다.

**Goal:** 현재 Streamlit 부동산 분석 앱에 `매수판단` 탭을 추가해 지역 A/B와 목적별로 가격 위치, 전세 지지력, 거래량 회복, 수요공급 압력, 입주물량 부담을 비교하고 판단 카드로 보여준다.

**Architecture:** 앱 UI는 `app.py`에서 담당하되, 판단 로직은 별도 모듈로 분리한다. 기존 `analysis.py`가 이미 존재하므로 즉시 `analysis/` 패키지 전환을 강행하면 import 충돌 위험이 있다. v1은 안전하게 `buy_decision/` 패키지로 신규 분석 로직을 만들고, v1 안정화 후 `analysis/` 패키지 전환을 별도 리팩터링으로 진행한다.

**Tech Stack:** Python 3.12, Streamlit, pandas, numpy, Plotly, pytest.

- 80점 이상: 관심 우선

주의:
- 등급은 투자 추천이 아니라 데이터 기반 비교 참고로 표시한다.
