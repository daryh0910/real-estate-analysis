# 변수 선택형 가설검증 데이터셋·수식환경 현황

## 1. 목표

부동산 가격분석 플랫폼에 다음을 검증할 수 있는 데이터셋과 수식환경을 확보한다.

1. 선택 지역·선택 면적대 아파트 매매가가 선택 소득분위의 소득/순자산 대비 얼마나 부담되는가?
2. 지역 GRDP와 집값 수준/상승률의 상관관계는 있는가?
3. 국민연금 데이터상 근로자 수 증가율, 1인당 고지금액 증가율과 집값 상승률은 상관관계가 있는가?
4. 같은 서울 안에서도 시군구별 구매력·고용·지역경제 변수와 집값 관계가 어떻게 다른가?

## 2. 변수 체계

필수 선택 변수:

- 지역: 시도, 시군구, 지역코드
- 면적: 전용면적 최소/최대값
- 기간: 시작연도, 종료연도
- 가격통계: 평균, 중위, q25, q75, q90
- 소득분위: 전체, 소득1분위, 소득2분위, 소득3분위, 소득4분위, 소득5분위
- 설명변수: 소득, 순자산, NPS 가입자수, NPS 1인당고지금액, GRDP 등

기본 예시:

```bash
python hermes/scripts/build_regional_hypothesis_dataset.py \
  --sido 서울 \
  --area-min 82 \
  --area-max 86 \
  --start-year 2017 \
  --end-year 2024 \
  --price-stat median \
  --income-quantile 소득5분위
```

강남구만 볼 때:

```bash
python hermes/scripts/build_regional_hypothesis_dataset.py \
  --sido 서울 \
  --sigungu 강남구 \
  --area-min 82 \
  --area-max 86 \
  --start-year 2017 \
  --end-year 2024 \
  --price-stat median \
  --income-quantile 소득5분위
```

- NPS는 직장가입자/사업장 소재지 proxy 성격이 강해 거주지 소득과 다를 수 있다.
