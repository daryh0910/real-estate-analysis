# 집값 설명·예측 가설 라이브러리와 필요 데이터셋

## 1. 목적

`real_estate_analysis`를 단순 시각화 대시보드가 아니라, 사용자가 직접 “왜 이 지역 집값이 오르거나 내리는가?”를 검증할 수 있는 가설검증 플랫폼으로 확장한다.

핵심 원칙:

- 종속변수: 선택 지역·선택 면적대 아파트 매매가 수준 또는 상승률
- 설명변수: 수요, 구매력, 고용, 공급, 금융, 심리, 입지, 정책
- 선택변수: 시군구, 면적범위, 기간, 가격통계, 소득분위, 설명변수, lag
- 모든 가설은 `수식 → 데이터셋 → 검증결과 → 한계`로 연결한다.

## 2. 가설 체계

### A. 구매력/소득 가설

| 가설 | 검증식 예시 | 필요 데이터 | 현재 상태 |
|---|---|---|---|
| 고소득·고순자산 가구의 구매력이 높은 시기에는 서울 핵심 면적대 가격이 지지된다 | `매매가 / 선택소득분위_소득`, `매매가 / 선택소득분위_순자산` | KOSIS 소득분위별 소득·순자산, 실거래 면적별 매매가 | 1차 확보 |
| 시군구 근로소득이 높은 지역일수록 집값 수준이 높다 | `corr(1인당총급여, 매매가)` | 국세청 시군구 근로소득 | 확보 |
| 사업장 소재지 기준 고임금 지역은 직주근접 수요로 가격이 높다 | `corr(NPS_1인당고지금액, 매매가)` | 국민연금 고지금액/가입자수 | 확보 |

주의:

- KOSIS 소득5분위는 전국 기준 분위다. 정확한 상위 10%는 소득10분위·순자산10분위 추가 확보 필요.
- NPS는 사업장 소재지 proxy라 거주지 소득과 다르다.

### B. 고용/지역경제 가설

| 가설 | 검증식 예시 | 필요 데이터 | 현재 상태 |
|---|---|---|---|
| 근로자 수가 증가하는 지역은 주택 수요가 증가한다 | `NPS_가입자수 YoY → 매매가 YoY` | 국민연금 가입자수 | 확보 |
| 사업장 수가 늘어나는 지역은 직주 수요·상권 활력이 높다 | `사업체수 YoY → 매매가 YoY` | SGIS/KOSIS 사업체 | 부분 확보/추가 필요 |
| GRDP가 증가하는 지역은 지역경제 현금흐름이 좋아 집값이 오른다 | `GRDP YoY → 매매가 YoY` | 시군구 GRDP | 확보, 최신성 부족 |
| 산업별 고용 증가가 지역별 집값 차이를 만든다 | `제조업/IT/금융 종사자 YoY → 매매가 YoY` | KOSIS 전국사업체조사/SGIS | 추가 필요 |

### C. 인구/수요 가설

| 가설 | 검증식 예시 | 필요 데이터 | 현재 상태 |
|---|---|---|---|
| 순유입이 강한 지역은 가격 상승 압력이 높다 | `순이동률 lag 6~12M → 매매가 YoY` | KOSIS 인구이동 | 수집 진행 |
| 30~49세 핵심 구매연령 인구가 늘면 가격이 오른다 | `30~49세 인구비중/증가율 → 매매가` | KOSIS 연령별 인구 | 확보 |
| 1·2인 가구 증가는 중소형 면적 수요를 만든다 | `1인가구비중 → 59㎡/84㎡ 가격` | KOSIS/SGIS 가구 | 부분 확보/추가 필요 |
| 고령화가 심한 지역은 장기 수요가 약하다 | `고령화율 ↑ → 매매가 상대성과 ↓` | 연령별 인구/SGIS 평균연령 | 확보/부분 확보 |

### D. 공급 가설

| 가설 | 검증식 예시 | 필요 데이터 | 현재 상태 |
|---|---|---|---|
| 입주예정물량이 많은 지역은 전세·매매 가격 압력이 낮아진다 | `입주예정세대 / 거래량 or 재고 → 매매가 YoY` | 단지별 입주예정 | 확보 |
| 인허가·착공·준공 증가 후 2~3년 뒤 공급 부담이 나타난다 | `착공 lag 24M`, `준공 lag 0~12M` | 건설 파이프라인 | 확보/수집 진행 |
| 미분양 증가는 지역 수요 약세 신호다 | `미분양 / 거래량 → 매매가 YoY` | 미분양 | 확보 |
| 노후주택 비중이 높은 곳은 재건축 기대가 가격에 반영된다 | `30년 이상 주택 비중 → 가격 프리미엄` | 주택총조사/건축물대장 | 추가 필요 |

### E. 금융/유동성 가설

| 가설 | 검증식 예시 | 필요 데이터 | 현재 상태 |
|---|---|---|---|
| 금리 하락은 DSR 기반 구매력을 높여 집값에 양의 영향 | `대출가능액(금리, 소득, DSR) → 매매가` | 기준금리/주담대금리/소득 | 부분 확보 |
| 주택담보대출 증가 지역은 수요가 강하다 | `주담대 YoY → 매매가 YoY` | BOK 주담대 시도 | 확보 |
| 예금/유동성 증가가 자산가격을 밀어올린다 | `M2/예금 YoY → 매매가` | BOK M2, 지역 예금 | 부분/추가 필요 |
| 예대금리차 확대는 금융환경 부담을 높인다 | `예대금리차 → 매매가/거래량` | BOK 예대금리차 | 추가 필요 |

### F. 심리/거래 가설

| 가설 | 검증식 예시 | 필요 데이터 | 현재 상태 |
|---|---|---|---|
| 주택가격전망 CSI가 상승하면 거래량과 가격이 선행 상승한다 | `CSI lag 3~6M → 거래량/매매가` | BOK CSI | 수집 진행 |
| KB 매수우위지수 상승은 가격 상승 압력을 반영한다 | `KB_매수우위 → 매매가` | KB 지표 | 수집 진행 |
| 거래량 회복은 가격 반등의 선행 신호다 | `거래량 YoY → 매매가 YoY` | 실거래 | 확보 |
| 전세수급지수 악화는 매매 전환 압력을 만든다 | `전세수급지수 → 매매가` | KB 전세수급/전세가격 | 수집 진행/부분 확보 |

### G. 입지/생활 인프라 가설

| 가설 | 검증식 예시 | 필요 데이터 | 현재 상태 |
|---|---|---|---|
| 학군·교육 인프라가 좋은 지역은 가격 프리미엄이 높다 | `학교/학원/학생수 proxy → 가격` | KOSIS 교육통계/data.go.kr | 추가 필요 |
| 병원·상권 등 생활 인프라가 좋은 지역은 선호도가 높다 | `병원수/사업체수/상권업종 → 가격` | HIRA/data.go.kr/SGIS | 추가 필요 |
| 교통망 개통 기대는 국지 가격 상승을 만든다 | `역 접근성/개통 더미 → 가격` | 철도역/도시철도/GTX 이벤트 | 추가 필요 |

### H. 정책/규제 가설

| 가설 | 검증식 예시 | 필요 데이터 | 현재 상태 |
|---|---|---|---|
| 규제지역 지정·해제는 거래량과 가격에 비대칭 충격을 준다 | `정책더미 × 지역 → 거래량/가격` | 규제지역 히스토리 | 확보 |
| DSR/LTV 완화는 고가주택보다 중저가 주택에 먼저 작동할 수 있다 | `정책더미 × 가격대` | DSR/LTV 이력, 실거래 | 확보/가공 필요 |

## 4. 수식환경에 필요한 공통 파생변수

### 가격

- `매매가_만원`
- `매매가_전년대비증가율`
- `거래량`
- `거래량_전년대비증가율`
- `면적대별_매매가`: 59㎡, 84㎡, 101㎡ 등 범위 선택

### 구매력

- `매매가_소득배율 = 매매가_만원 / 선택소득분위_가구소득`
- `매매가_순자산배율 = 매매가_만원 / 선택소득분위_순자산`
- `순자산_매매가커버리지 = 선택소득분위_순자산 / 매매가_만원`
- `대출가능액 = PMT 역산(소득, DSR, 금리, 기간)`
- `총구매력 = 순자산 + 대출가능액`
- `구매력_커버리지 = 총구매력 / 매매가`

### 고용/경제

- `NPS_가입자수_전년대비증가율`
- `NPS_1인당고지금액_전년대비증가율`
- `GRDP_전년대비증가율`
- `1인당총급여_전년대비증가율`

### 인구

- `순이동률 = 순이동자수 / 총인구`
- `30_49세_인구비중`
- `30_49세_인구증가율`
- `고령화율`

### 공급

- `입주예정세대_12M`
- `입주예정세대_24M`
- `입주부담 = 입주예정세대 / 최근12개월거래량`
- `미분양률_proxy = 미분양 / 주택수 또는 거래량`
- `착공_24M_lag`, `준공_12M_lag`

### 심리/금융

- `주택가격전망CSI`
- `KB_매수우위지수`
- `KB_전세수급지수`
- `기준금리`
- `주담대증가율`
- `M2증가율`

## 5. 우선 구현 순서

1. 현 산출 스크립트 `build_regional_hypothesis_dataset.py`에 다음 변수를 순차 merge
   - 국세청 근로소득
   - 인구 연령대별 핵심 구매연령
   - 인구이동
   - 미분양/입주예정/건설파이프라인
   - BOK/KB 시도 단위 금융·심리 지표

2. App UI
   - 기존 `수식 계산기` 탭을 “가설검증” 탭으로 확장
   - 지역/면적/기간/소득분위/설명변수/lag 선택
   - scatter, lag chart, correlation table, region ranking 제공

3. 예측모델
   - 1단계: 단순 상관/lag 상관
   - 2단계: 회귀분석 + 지역 fixed effect
   - 3단계: train/test split 기반 예측력 검증
   - 4단계: feature importance, SHAP 등 설명가능성

## 6. 데이터 한계와 주의

- 시군구 단위와 시도 단위 지표가 섞인다. 시도 지표는 broadcast하되 해석에 주의해야 한다.
- 연간 지표는 월별 가격 예측에 쓸 때 공표 lag를 둬야 한다.
- 가격과 동시성이 강한 지표는 설명력은 높지만 예측에서는 leakage가 생길 수 있다.
- NPS는 사업장 기준, 국세청 근로소득은 납세/근로소득자 기준, KOSIS 소득분위는 전국 가구 기준이다.
- “상위 10%”는 아직 정확한 공개 테이블을 찾지 못했으므로, 현재는 소득5분위/순자산 proxy로 운용한다.
