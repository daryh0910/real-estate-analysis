# 데이터 신뢰도/출처 표시 설계

> 작성일: 2026-05-12  
> 대상: 입주·공급맵, Superchart, 게시판 공유 payload  
> 참고 파일: `data_loader.py`, `update_all.py`, `cache/`, `README.md`, `app.py`

## 1. 핵심 결론

투자 판단용 앱이므로 모든 입주·공급 및 Superchart 화면에 다음 4가지를 고정 노출해야 한다.

1. 데이터 기준일: 원천 데이터의 최신 `연월/연도`와 캐시 생성 시각을 분리 표시
2. 출처: 원천기관, 수집 스크립트, 파생 여부를 지표 단위로 표시
3. 신뢰도: 누락률, 지역 커버리지, 지연개월, 품질 등급을 표시
4. 주의문구: 월 단위 업데이트, 실시간 미반영, 입주예정 변동 가능, 투자 책임 고지

ASIL처럼 단순 문구를 하단에 두되, 우리 앱은 Superchart/게시판 공유까지 재현 가능해야 하므로 metadata schema를 별도 파일 또는 DB payload로 관리하는 구조가 필요하다.

## 2. 현재 구조에서 확인한 사항

## 2.1 데이터 로딩 구조

`data_loader.py` 기준 주요 데이터:

- 실거래 매매/전세/월세: 원본 CSV → `cache/*.parquet`
- 공급: `인허가_호수`, `착공_호수`, `준공_호수`, `미분양_호수`, `주택보급률`
- 수요/금융/심리: NPS, BOK, KOSIS, KB, KRIHS 등
- 병합 결과: `yearly`, `monthly`

현재 공급 관련 로더:

- `load_permit_data()`
- `load_construction_data()`
- `load_unsold_housing_data()`
- `load_housing_supply_data()`

## 2.2 업데이트 구조

`update_all.py`는 데이터별 label, 수집 함수, 시점 컬럼을 이미 가지고 있다.

- `MONTHLY_CSV_MAP`: 미분양, 기준금리, 지가변동률, 전월세전환율, 주택가격지수, 인구이동, 착공/준공, 주담대, NPS
- `YEARLY_CSV_MAP`: KOSIS 가계자산, 소득5분위, 국세청 근로소득
- 증분 업데이트 시 이전 종료/현재 종료를 요약 출력

하지만 이 실행 결과가 앱에서 재사용 가능한 metadata로 저장되지는 않는다.

## 2.3 캐시 파일

현재 `cache/` 확인 파일:

- `apt_sigungu_monthly.parquet`
- `apt_sigungu_monthly_detail.parquet`
- `jeonse_sigungu_monthly.parquet`
- `wolse_sigungu_monthly.parquet`
- `rent_all_sigungu_monthly.parquet`
- `kosis_population_age_sido_yearly.csv`
- `kosis_population_age_sigungu_yearly.csv`
- `sgis_house_sido_yearly.csv`
- `sgis_household_sido_yearly.csv`
- `sgis_population_sido_yearly.csv`

현재 `app.py`에는 `_dataset_quality_snapshot()`가 있어 행수, 지역수, 결측있는지역, 캐시파일 수, 최신 cache mtime을 표시하지만, 원천별 기준일/출처/지연개월/누락률은 부족하다.

## 3. 데이터 신뢰도 패널 설계

## 3.1 공통 위치

### A. 입주·공급맵

상단 KPI 아래 또는 화면 하단 고정 expander:

- 짧은 한 줄: `데이터: 2026-04 기준 · 출처: 국토부/KOSIS/BOK · 월 단위 업데이트 · 입주예정 변동 가능`
- 상세 expander: `데이터 신뢰도/출처 상세`

### B. Superchart

차트 제목 아래 caption:

- `사용 지표 기준일: 매매 2026-04, 준공 2026-03, 미분양 2026-03 · 출처 상세 보기`

차트 우측 또는 하단 expander:

- 선택된 지표만 필터링해서 metadata 표시
- 파생지표는 원천 지표 목록과 계산식 표시

### C. 게시판 공유

게시글 본문 하단 자동 첨부:

- `이 차트의 데이터 기준일`
- `사용 지표/출처`
- `주의문구`
- `chart_settings.data_metadata_snapshot`

게시글 생성 시점의 metadata snapshot을 저장해야 이후 원본 데이터가 업데이트되어도 당시 분석 기준이 보존된다.

---

## 3.2 패널 요약 카드

패널 상단 4개 카드:

1. 최신 기준월
   - 예: `2026-04`
   - 선택 지표 중 가장 오래된 기준월도 함께 표시: `최저 최신성: 준공 2026-02`

2. 지역 커버리지
   - 예: `17/17 시도`, `229/250 시군구`
   - 선택 지역 단위와 실제 데이터 단위가 다르면 경고

3. 누락률
   - 예: `전체 3.2%`, `선택 지역 0.0%`
   - 기준: 필수 지표의 `NaN / 기대 셀 수`

4. 신뢰도 등급
   - A: 지연 2개월 이하, 누락률 5% 이하, 지역 커버리지 95% 이상
   - B: 지연 4개월 이하, 누락률 15% 이하
   - C: 지연 6개월 이하 또는 지역 일부 누락
   - D: 기준일 불명/출처 불명/누락률 30% 이상

## 5. 앱 화면 표기 문구

## 5.1 입주·공급맵 기본 문구

짧은 caption:

> 데이터 기준: {기준월} · 출처: {출처목록} · 월 단위 업데이트 · 입주예정/준공 정보는 변경될 수 있습니다.

상세 주의문구:

> 본 입주·공급 데이터는 공공데이터 및 보유 원천자료를 월 단위로 집계한 참고 정보입니다. 실시간으로 모든 입주예정 단지, 일정 변경, 세대수 변경을 반영하지 않을 수 있습니다. 인허가·착공·준공은 서로 다른 공급 단계이며 실제 입주 가능 시점과 차이가 날 수 있습니다. 투자 판단 전 원천자료와 현장 정보를 반드시 재확인하세요.

## 5.2 Superchart 문구

차트 하단:

> 이 차트는 선택 지표의 기준일이 서로 다를 수 있습니다. 파생지표는 원천 데이터의 결측·지연·지역 단위 차이를 상속합니다.

선택 지표 기준일 예시:

> 기준일: 매매 실거래 2026-04 / 전세 실거래 2026-04 / 준공 2026-03 / 미분양 2026-03

## 5.3 게시판 공유 문구

게시글 하단 자동 첨부:

> 이 게시글은 작성 시점의 데이터 기준일과 차트 설정을 함께 저장합니다. 이후 원천 데이터가 업데이트되면 동일 설정을 다시 불러와도 수치가 달라질 수 있습니다.

## 5.4 출처 불명/낮은 신뢰도 문구

- 출처 불명: `출처가 확인되지 않은 데이터입니다. 공유 및 투자 판단에 사용하지 않는 것을 권장합니다.`
- 오래된 데이터: `선택 지표 중 일부가 {N}개월 이상 갱신되지 않았습니다.`
- 지역 단위 불일치: `이 지표는 {원천단위} 단위 데이터로, 선택한 {화면단위}에 균등/상위단위 값으로 표시됩니다.`
- 누락률 높음: `선택 구간의 결측률이 {누락률}%입니다. 차트 해석에 주의하세요.`

## 6. 자동 검증 지표 설계

## 6.1 필수 지표

1. 최신성
   - `as_of`: max(연월/연도)
   - `lag_months`: 현재 월 - as_of
   - 월간 데이터 경고 기준: 3개월 이상 지연 warning, 6개월 이상 error
   - 연간 데이터 경고 기준: 18개월 이상 지연 warning

2. 누락률
   - `missing_rate = 결측 셀 수 / 기대 셀 수`
   - 선택 지역/기간 기준과 전체 데이터 기준을 모두 산출

3. 지역 커버리지
   - `coverage_rate = 실제 지역 수 / 기대 지역 수`
   - 시도 기준 기대값: 17개
   - 시군구 기준은 행정구역 코드 테이블 필요. 초기에는 데이터 내 최대 지역수 대비로 계산 가능

4. 중복률
   - key = `[연월, 시도]` 또는 `[연월, 지역코드]`
   - `duplicate_count > 0`이면 warning

5. 이상치
   - 전월 대비 변화율 z-score 또는 IQR
   - 공급/거래량은 0 또는 급등이 정상일 수 있으므로 이상치가 아니라 `확인필요`로 표시

6. 음수/범위 검증
   - 세대수, 거래량, 인허가, 착공, 준공, 미분양: 0 이상
   - 비율 지표: 합리 범위 설정
   - 날짜: 미래 과다/불가능 날짜 확인

7. 캐시 일관성
   - parquet mtime이 원본 CSV mtime보다 오래되면 `캐시 재빌드 필요`
   - `update_all.py` 실행 결과와 cache mtime 비교

8. 지표 단위 일관성
   - 같은 차트 내 전국/시도/시군구 단위 혼합 여부
   - Superchart에서 다른 단위 혼합 시 caption 경고

## 6.2 품질 등급 산식 v1

```text
A = 출처 확인 + 기준일 존재 + lag_months <= expected_lag+1 + 누락률 <= 5% + 커버리지 >= 95%
B = 출처 확인 + 기준일 존재 + 누락률 <= 15% + 커버리지 >= 85%
C = 출처 확인 + 기준일 존재 + 누락률 <= 30%
D = 출처 불명 또는 기준일 없음 또는 누락률 > 30% 또는 필수 컬럼 누락
```

등급은 확정적 신뢰도라기보다 “앱 내부 데이터 사용 가능성”으로 표시한다.

권장 라벨:

- A: 양호
- B: 주의
- C: 제한적 사용
- D: 사용 비권장

## 8. 수용 기준

- 입주·공급맵에서 사용자가 스크롤 없이 기준월/출처/주의문구를 확인할 수 있다.
- Superchart에서 선택한 모든 지표의 기준일과 출처를 확인할 수 있다.
- 게시판 공유 payload에 `data_metadata_snapshot`이 저장된다.
- 출처 또는 기준일이 없는 지표는 공유 시 경고된다.
- 자동 검증 결과로 최신성, 누락률, 지역 커버리지, 품질등급이 산출된다.
- ASIL과 동일하게 월 단위 업데이트 및 실시간 미반영 주의문구가 명확히 보인다.
